# UHC Control

UHC Control is a Minecraft: Java Edition datapack that provides the basis for running Ultra Hardcore (UHC) games. It handles game setup, configuration, and timing management, with optional expansion datapacks for additional features.

---

## Supported Versions

- v2.0.11 - Minecraft: Java Edition 1.21.1 – 1.21.11
- v2.1.0 - Minecraft: Java Edition 1.21.11

---

## Quick Start

1. [Download](https://sites.google.com/view/monkeyarmoury/uhc-control) and install the datapack in your world's `datapacks` folder.
2. Run `/function #uhc:admin/setup` in-game.
3. You will receive the UHC Control Book, which is used to configure all game options. 
> **Note**: Admins **must be in Creative mode** for full functionality of the UHC Control Book.
4. Configure the game options using the book.
5. Once all players have joined and teams are set, press **Start**.

To uninstall the datapack safely run `/function #uhc:admin/uninstall` and then delete the datapack from your world.
> **Note:** Gamerules and world spawn are not reverted on uninstall.

---
