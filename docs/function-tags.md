# Function Tags

## Utilisation

## List of function tags

|Admin| |
|---|---|
|#uhc:admin/setup        |The first function tag run to setup and initialise UHC Control|
|#uhc:admin/uninstall    |Uninstall traces of UHC Control|

|Game| |
|---|---|
|#uhc:game/death         |Run when a player dies during a UHC game|
|#uhc:game/marker        |Run for every minute marker as configured before a UHC game|
|#uhc:game/minute        |Run every minute during a UHC game|
|#uhc:game/player_join   |Run when a player joins the server whilst a UHC game is running|
|#uhc:game/second        |Run every second during a UHC game|
|#uhc:game/start         |Run at the beginning of a UHC game|

|Lobby| |
|---|---|
|#uhc:lobby/player_join  |Run when a player joins the server whilst in the Lobby|
|#uhc:lobby/second       |Run every second whilst in the Lobby|
