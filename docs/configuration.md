## Game Rules
**Fire Spread**
(Default: False): When true, fire can spread.

**Hurt Own Team**
(Default: True): When true, players can cause damage to members of their own team.

**Locator Bar**
(Default: False): When true, the locator bar feature is enabled. 

**Natural Health Regeneration**
(Default: False): When true, players can regenerate their health using hunger.

**Raids**
(Default: False): When true, players with the Bad Omen effect when entering a village trigger a raid.

**Show Advancement Messages**
(Default: False): When true, advancement messages are displayed in chat.

**Spawn Patrols**
(Default: True): When true, pillager patrols can spawn.

**Spawn Phantoms**
(Default: False): When true, phantoms can spawn.

**Spawn Wandering Traders**
(Default: True): When true, wandering traders can spawn.

**Spawn Wardens**
(Default: True): When true, wardens can spawn.
